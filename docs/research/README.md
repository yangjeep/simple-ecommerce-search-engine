# Research notes

Exploratory material lives here: prior-art archaeology, paper/thesis work, economic models, rubrics and methodology/generalization research.

A research note may motivate an experiment, but it is not itself a promoted system verdict. Promoted conclusions belong in [`../decisions/`](../decisions/); detailed measurement history belongs in [`../experiments/`](../experiments/).

`artifacts/` contains bulky supporting outputs and should not be treated as the narrative entry point.
