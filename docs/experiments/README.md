# Experiment archive

This directory contains the detailed research record: protocols, append-only logs, correction notes and adversarial-review findings.

Use [`../decisions/`](../decisions/) for quick verdicts. Use this directory when auditing **how** a verdict was reached.

Naming is historical and intentionally preserved (`PHASE*_LOG.md`, `ISSUE*_PROTOCOL.md`, etc.). Do not reorganize individual logs by topic; that would make experiment provenance harder to follow.

Supporting machine-readable definitions/results live in `../../benchmarks/manifests/`, `../../artifacts/manifests/` and `../research/artifacts/`.
